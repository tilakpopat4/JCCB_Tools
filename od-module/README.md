# ધી જૂનાગઢ કોમર્શીયલ કો-ઓપરેટીવ બેંક લી.
## The Junagadh Commercial Co-Operative Bank Ltd.
### ઓવરડ્રાફ્ટ લોન ફોર્મ, રજીસ્ટર, રીપોર્ટ અને પ્રિન્ટિંગ મોડ્યુલ (Overdraft Loan Against Fixed Deposit Module)

આ મોડ્યુલ **The Junagadh Commercial Co-Operative Bank Ltd.** ની શાખાઓમાં ગ્રાહકોને ફિક્સ ડિપોઝિટ (FD) રસીદ સામે ઓવરડ્રાફ્ટ (OD) લોન આપવા માટેનું એક સંપૂર્ણ, આધુનિક અને ઓફલાઇન વેબ મોડ્યુલ છે.

#### ૨. કસ્ટમર અને સંયુક્ત અરજદારો (Dynamic Joint Applicants):

#### ૩. લોન વિગતો અને સેવિંગ ખાતા નંબર:
- આજની તારીખ આપોઆપ આવી જાય છે.
- **સેવિંગ ખાતા નંબર**: ફરજિયાત ન્યુમેરિક અને ફિક્સ ૧૫ આંકડાનું લાઈવ વેલિડેશન.
- **લોનની રકમ**: દાખલ કરતાં જ ગુજરાતી (રૂપિયા ... પૂરા) અને અંગ્રેજી (RUPEES ... ONLY) માં આપોઆપ શબ્દોમાં રૂપાંતરિત થાય છે.

#### ૪. ફિક્સ ડિપોઝિટ રસીદોનું ટેબલ (Tabular Format):
- કોલમ્સ: ક્રમ, સર્ટીફીકેટ નંબર, થાપણ મૂક્યા તારીખ, થાપણની પાકતી તારીખ, થાપણની રકમ રૂ., લોનની રકમ રૂ.
- `+ રસીદ ઉમેરો` બટન વડે ગમે તેટલી લાઈનો ઉમેરી શકાશે.
- કુલ થાપણ રકમ અને કુલ લોન રકમનો આપમેળે સરવાળો (Auto Total) થાય છે.

#### ૫. ફોર્મ રજીસ્ટર (Loan Register):
- સેવ કરેલા તમામ રેકોર્ડ્સ રિયલ-ટાઇમ લિસ્ટમાં દેખાય છે (નવા રેકોર્ડ્સ સૌથી ઉપર).
- સર્ચ બાર (ગ્રાહક નામ, ID, ખાતા નંબર, રસીદ નંબર દ્વારા).
- શાખાવાર ફિલ્ટર.
- Edit (ફોર્મમાં ડેટા પાછો લોડ થાય છે), Delete, Direct Print.
- ડેટા સેવિંગ માટે **Export Backup (JSON)** અને **Import Backup** ની સુવિધા.

#### ૬. રીપોર્ટ મોડ્યુલ (Reports & Analytics):
- કુલ અરજીઓ, કુલ ધિરાણ રકમ, કુલ તારણ FD રકમ અને સરેરાશ વ્યાજદરના KPI કાર્ડ્સ.
- શાખાવાર ઓવરડ્રાફ્ટ ધિરાણ વિશ્લેષણ ટેબલ.
- CSV / Excel એક્સપોર્ટ બટન.
